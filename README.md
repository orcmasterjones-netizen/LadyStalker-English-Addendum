# LadyStalker-English-Addendum
Lady Stalker English Translation Hack Addendum

This hack is an addendum to  [Retch’s Lady Stalker English Translation](https://www.romhacking.net/translations/7687/), cleaning up the menus and ensuring all of the important text appears in English.  Text such as the battle messages will now appear in English.  Other changes include altering the font to match Landstalker's font, variable width text for item menus, and restoring the NPC voice sounds.   Two patches are included in the linked GitHub repository, one that can be applied to a ROM patched with Retch's translation patch, and another that can be applied directly to the original Japanese ROM.

The game has been tested from start to finish, with no major issues found.   There are some minor graphical issues present in Versions 1.0 and 1.1, such as dark lines flashing for a few frames during some menu transitions.  However, everything is fully functional. The graphical issues should be gone completely now in Version 1.2.

Version History: 

Version 1.1 simply revises the text in the library area to ensure the puzzles make sense, and fixes the slot-machine prize message so that it displays "COINS WON!" in English. No gameplay behavior, audio, spell names, or unrelated text was changed.

Version 1.2 fixes the minor graphical issues, and makes some minor adjustments to the text, primarily cutting the length of some battle messages so they aren't overly long and can appear properly.  The shop dialogue was also slightly altered to make the speed of purchasing multiple items in a row closer to the Japanese version.

Version 1.2 fixes the minor graphical issues, and makes some minor adjustments to the text, primarily cutting the length of some battle messages so they aren't overly long and can appear properly.  The shop dialogue was also slightly altered to make the speed of purchasing multiple items in a row closer to the Japanese version.

Version 1.3 cleans up the text so that the dialogue doesn’t get cutoff mid-word anymore in the text boxes. This makes the text look cleaner and display faster in those cases, because it removes the unnecessary newlines. Some menu operations have also been improved and cleaned up, so they will be both visually cleaner and closer in speed to the original Japanese version.

Version 1.4 most notably removes all the abbreviations previously used to fit item and spell/skill names into windows.  The full names will now be displayed.  It also cleans up the text further, and removes some minor graphical issues during events occurring after key item usage.
